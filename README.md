# ASP.NET ile Web Programlama - BTK Akademi

Bu depo, **BTK Akademi** bünyesindeki **"ASP.NET ile Web Programlama"** eğitimi ve staj faaliyetleri kapsamında geliştirilen tüm modülleri, mimari yaklaşımları ve pratik projeleri içermektedir.

Eğitim süresince temel C# ve web mimarisinden başlanarak; MVC tasarım deseni, Razor Pages sayfa mimarisi, RESTful Web API geliştirme, Entity Framework Core ORM yönetimi, Typed HttpClient ile API tüketimi ve modern Frontend entegrasyonu (Vanilla JS / Fetch API) uçtan uca uygulanmıştır.
